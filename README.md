# Financial Reporting and Variance Analysis

## Project Status

🚧 **In Progress**

This project is currently being developed in stages. The dataset, analysis workflow, dashboard and documentation will be added progressively.

## Project Overview

This project simulates a financial reporting and variance analysis process for a fictional multi-branch company.

The objective is to compare actual financial performance against budget, identify significant variances and translate the results into clear management insights.

The project will demonstrate how Excel, Power Query, SQL and Power BI can be used together across a practical finance reporting workflow.

## Business Objective

Management requires a reliable monthly reporting process to understand:

* whether revenue and expenses are performing according to budget
* which branches or departments are contributing to major variances
* which accounts require further investigation
* how financial performance changes across reporting periods
* what management actions may be required based on the results

## Planned Analysis

The project will focus on:

* budget versus actual performance
* revenue and expense variance
* favourable and unfavourable variance classification
* monthly financial trends
* branch and department performance
* account-level variance analysis
* identification of significant or unusual transactions
* management commentary and recommendations

## Planned Workflow

1. Prepare the source data in Excel.
2. Clean and transform the data using Power Query.
3. Validate and analyse selected records using SQL.
4. Build financial measures and a reporting model in Power BI.
5. Create an interactive financial reporting dashboard.
6. Document the findings, assumptions and data-quality checks.

## Tools

* **Excel** — source data preparation, formulas, validation and reconciliation
* **Power Query** — data cleaning, transformation and consolidation
* **SQL** — data validation, aggregation and exception analysis
* **Power BI** — data modelling, calculations and dashboard reporting
* **GitHub** — project documentation and portfolio presentation
